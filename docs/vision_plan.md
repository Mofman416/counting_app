- This program is made with the intent to collect a master sales sheet, gather the data that is being recorded in it, and collect supplemental "correct" data to compare with the master sales sheet and observe any discrepancies.

- The program will also collect labor reports to calculate how much labor is being spent in a set period based on similar reports.

- The target user is the general manager of Arby's who use the data collection system that they use in the store (Needs the name of the software they use.)

- The timeline is ideally before winter break is over, however more time can be used.

- A risk include scope creep, which can be mitigated with the time to learn how to integrate the features needed.

- If other managers other than the intended General Manager wants to use this software, they may purchase it.
